❄️ Financial Analytics: Financial Insights Dashboard

A dynamic and interactive Power BI dashboard designed to analyze global financial data—focusing on Country, Segments, Units Sold, Profit, Cost Price, and Sales. This dashboard enables users to explore trends, compare performance across countries, and uncover key financial insights for strategic decision-making.

📌 1. Short Description / Purpose

The Financial Insights Dashboard provides a visually rich and interactive way to explore global financial patterns across countries and business segments. It helps users identify trends in Units Sold, Sales, Profit, and Cost Price, supporting data-driven decision-making for financial teams and business leaders.

🛠 2. Tech Stack

The dashboard was built using the following tools and technologies:

📊 Power BI Desktop – Core platform for visualization and report development

📂 Power Query – Used for transforming, cleaning, and preparing raw financial data

🧠 DAX (Data Analysis Expressions) – Created calculated measures, KPIs, and dynamic logic

📝 Data Modeling – Fact and dimension table relationships for accurate filtering

📁 File Formats – .pbix for development, .png for dashboard preview images

📄 3. Data Source

Source: Global Financial Transactions Dataset (custom/open-source).

The dataset includes:

Country-wise and segment-wise sales

Units Sold

Profit & Profit Margin

Cost Price and Revenue

Time-based financial metrics

The structure includes fact tables (Sales, Profit, Pricing) and dimension tables (Country, Segment, Product, Time).

⭐ 4. Features / Highlights
🔹 Business Problem

Companies operating across multiple countries lack a unified, interactive way to compare financial performance. Critical questions such as:

Which markets generate the highest sales and profit?

Which segments are performing the best?

Where is high sales volume not translating into profit?
… are difficult to answer with static spreadsheets.

🔹 Goal of the Dashboard

To build an interactive financial tool that:

Compares performance across countries and segments

Shows patterns in cost, profit, and sales

Highlights high-potential and low-performing markets

Supports decision-making for pricing, budgeting, and forecasting

🔹 Walkthrough of Key Visuals

Key KPIs (Top Section)
Displays Total Units Sold, Total Profit, Total Sales, Avg. Cost Price, and coverage metrics.

Country & Segment Filters
Interactive slicers to filter visuals by Country, Segment, Product, and Time.

Country-wise Sales & Profit (Bar Chart)
Ranks top-performing and underperforming countries.

Segment Performance (Column Chart)
Shows which business segments drive the most revenue and profit.

Cost vs Profit Margin (Scatter / Line Chart)
Helps identify markets with high cost impact.

Units Sold Distribution (Map / Bar Chart)
Highlights where product demand is strongest.

Sales Trend Over Time (Line Chart)
Supports forecasting and seasonality analysis.

🔹 Business Impact & Insights

Helps identify countries with high sales but low profit margins

Reveals segment-wise financial opportunities

Supports cost optimization decisions

Enhances strategic planning through trend and performance insights

Enables teams to transition from static reports to interactive analysis
